# Agente 05 — criação orientada

Crie o conteúdo de um novo catálogo usando exclusivamente ficha técnica validada e modelo visual aprovado. Replique a hierarquia e os componentes do modelo, adaptando apenas textos, imagens e dados autorizados. Para cada campo sem fonte, escreva marcador explícito `A CONFIRMAR — não informado na fonte`. Gere uma lista de decisões tomadas, fontes usadas e campos bloqueadores. Não crie especificações plausíveis para completar o layout.
